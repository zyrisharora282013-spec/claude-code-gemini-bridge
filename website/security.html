Security & Privacy

Plain language, no marketing gloss.

What stays on your machine

  • The proxy runs locally and listens on 127.0.0.1 only by default.
  • Your Google OAuth tokens are stored on your computer in a file with owner-only permissions. They are sent only to Google to authenticate your requests.
  • This website is static: no accounts, no backend, no analytics, no cookies, no secrets.

What leaves your machine

Your prompts and code context go to Google's Cloud Code API, because that is where Gemini runs. Treat that like any cloud AI service.

Hardening

  • Requests from non-local browser origins and Host headers are rejected (CSRF and DNS-rebinding protection).
  • Dashboard password is stored hashed with scrypt; repeated wrong passwords trigger a temporary lockout.
  • Strict Content-Security-Policy, X-Frame-Options and Referrer-Policy on the dashboard.
  • Email addresses are masked in logs.
  • CI runs tests, dependency audit and CodeQL.

Google's terms

The bridge uses Google's Cloud Code API with your Google account. Google's terms apply, and Google may restrict access at its discretion. Review them before using the bridge. This project is not affiliated with or endorsed by Google or Anthropic.

Do not host it publicly

Do not expose the proxy to the internet or to other people. Anyone who can reach it can use your linked accounts.
