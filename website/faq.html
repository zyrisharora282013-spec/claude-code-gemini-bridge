FAQ

Is this an official Anthropic or Google product?

No. It is an independent open-source project.

Does it cost money?

The bridge is free. Your usage is subject to the quotas and terms of your Google account.

Where do my tokens go?

They are stored on your computer and sent only to Google. See Security & Privacy.

Is it allowed by Google's terms?

It uses Google's Cloud Code API through your account, so Google's terms apply and access can be restricted at Google's discretion. Read them and decide for yourself.

Claude Code says "API error, retrying".

The proxy likely has no linked account. Open http://localhost:8085/ and add one.

Port 8085 is in use.

Change the port in %USERPROFILE%\.config\antigravity-proxy\config.json.

Does it work on macOS or Linux?

The proxy is Node.js and should run anywhere, but the installer and scripts target Windows.

Can I host it for other people?

Please don't. A hosted proxy would hold other people's Google tokens, which is a security and legal risk.
