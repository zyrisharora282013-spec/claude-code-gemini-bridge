Install guide

Windows 10/11. You need Node.js 18+ and the Claude Code CLI.

Option A: Installer

  1. Download Installer.exe and its SHA-256 checksum from the Download page.
  2. Verify the checksum: Get-FileHash .\Installer.exe -Algorithm SHA256 and compare it to the published value.
  3. Run the installer. It configures Claude Code, adds the claude-gemini command and starts the proxy on port 8085.

Option B: PowerShell setup

git clone https://github.com/VanshCoder01/claude-code-gemini-bridge
cd claude-code-gemini-bridge
npm run setup

Prefer to inspect first? Read scripts/setup.ps1 before running it.

Link your Google account

  1. Open http://localhost:8085/ in your browser.
  2. Click Add Account and sign in with Google.
  3. Run claude-gemini in any terminal.

Optional: your own OAuth client

The bundled Google OAuth client is a shared default. For long-term use, create your own in Google Cloud Console and set OAUTH_CLIENT_ID and OAUTH_CLIENT_SECRET environment variables.
