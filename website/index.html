Open source · Windows · runs 100% locally

Claude Code, powered by Gemini

A small local proxy translates Claude Code's Anthropic API calls to Google's Cloud Code API, with multi-account load balancing and a dashboard to manage it all.

Download Install guide

How it works

Features

Multi-account balancing

Link several Google accounts. The proxy rotates them when one is rate-limited.

Local dashboard

Manage accounts, models, logs and settings at localhost:8085.

Tool calls & streaming

Anthropic-compatible streaming and tool use, so Claude Code keeps working normally.

Hardened by default

Loopback-only, CSRF/DNS-rebinding protection, hashed dashboard password and login lockout.

One-click installer

A Windows installer, or a PowerShell setup script if you prefer to read what runs.

Open source

MIT licensed. Read every line on GitHub before you run it.

Honest note: this project uses Google's Cloud Code API through your own Google account, so Google's terms apply and access may be restricted at Google's discretion. Review them before use.
