Windows installer

Installer.exe plus a SHA-256 checksum file, built by CI from the public source.

Open GitHub Releases

Verify your download

Get-FileHash .\Installer.exe -Algorithm SHA256

Compare the hash with the one published next to the release. If they differ, do not run the file.
